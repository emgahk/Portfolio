English Professor / Teacher ePortfolio

파일 구성
- index.html : 페이지 구조 및 텍스트
- style.css  : 디자인, 반응형 레이아웃, 애니메이션
- script.js  : 스크롤 효과, 모바일 메뉴, 강의 모달, 버튼 인터랙션

수정 우선순위
1. HTML에서 '✓' 검색 → 교체가 필요한 사진/텍스트/연락처를 빠르게 확인
2. 사진 placeholder 영역을 <img> 요소로 교체
3. 강의명, 연구 분야, 논문/저서, 학생 프로젝트를 실제 내용으로 수정
4. 이메일 및 외부 프로필 링크 수정

사진 넣는 예시
<div class="project-image ...">...</div>
를 아래처럼 교체:
<img class="project-image" src="images/classroom.jpg" alt="문학 세미나 수업 모습">

로컬 실행
index.html을 브라우저에서 바로 열어도 동작합니다.
